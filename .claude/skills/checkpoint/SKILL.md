# チェックポイント — 作業状態の保存

１）`thinking-log/NOW.md` を上書き更新する。書くのは3つだけ:
　・いま何をしていたか
　・次に何をするか
　・宙に浮いている一手（返事待ち・判断待ちなど）
２）**30秒で読める分量**に保つ。古い内容は消してよい（揮発メモ。残すべき決定は /log で別途残す）。
３）タスクの一覧をここに溜め込まない。「いま進行中のスレッドの次の一手」だけ。
４）commit + push する（メッセージ例: `checkpoint: ◯◯の途中、次は◯◯`）。
５）pushまで確認できたら「保存した」と一言で報告。次のセッション（別の端末でも）はここから再開できる。
