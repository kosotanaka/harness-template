# thinking-log エントリ作成

正本の書式は `thinking-log/FORMAT.md`。この手順はその実行ラッパー。

１）1テーマ1ファイル。`thinking-log/YYYY/YYYY-MM-DD_テーマ.md`
２）冒頭に結論。経緯はその下。未来の自分（とAI）が3分で文脈を取り戻せる形に。
３）必須要素: 判断の理由／捨てた選択肢とその理由／**見直し条件**（この前提が崩れたら再検討する、を1行）。
４）書き終えたらcommit + push。
５）NOW.mdの「次にやること」に影響するなら、NOW.mdも同時に更新するか /checkpoint を促す。
６）その決定が「みんなの知見」（案件の経緯・判断の型・やり方のコツ）を含むなら、/wiki（kosowiki行き）も提案する。個人の作業ログはハーネスに留める。
