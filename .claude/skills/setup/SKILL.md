# セットアップ

リポジトリの外（claude.ai側）にある設定を、この会話の中で片付ける。
人間向けの説明は `SETUP.md`。この手順はその実行版。

**原則: 相手の「繋ぎました」を信用しない。必ず自分で叩いて確かめる。**
コネクタは中途半端に繋がると、エラーではなく**空の結果**を返す。それが一番見つけにくい壊れ方なので、
このスキルの価値はほぼ全部「検証」にある。案内文を読み上げるだけなら意味がない。

---

## 1. 名乗ってもらう（AGENTS.mdがまだテンプレのままなら）

`AGENTS.md` の「1. あなたについて」に `【` が残っていたら、先にここを埋める。
名前・担当・いま力を入れていること、の3つを聞いて書き換え、commit する。
埋まっていれば飛ばす。

## 2. 何が繋がっているかを実際に叩いて調べる

ツールは遅延読み込みなので、まず ToolSearch で必要なものを引く。
そのうえで**1つずつ、実際に軽い読み取りを投げる**。返ってきたかどうかで判定する。

| 見るもの | 叩くもの | 通った判定 |
|---|---|---|
| Google カレンダー | `list_calendars` | カレンダーが1つ以上返る |
| Gmail | `list_labels` | ラベルが返る |
| Google Drive | `list_recent_files` | ファイルが返る（0件でもエラーでなければ可） |
| Slack | `slack_search_channels`（クエリは短く） | チャンネルが返る |
| GitHub | `get_me` | ログイン名が返る |
| Tactiq | `list_recent_meetings` | 会議一覧が返る（有料プラン外なら案内文が返る＝接続は生きている） |

判定の注意。

・**ツールがそもそも存在しない** → コネクタ未接続。
・**ツールはあるが権限エラー** → 認可が途中で切れている。403系は `SETUP.md` の復旧手順へ。
・**空で返る** → 判断を保留する。「本当に0件なのか、見えていないのか」を切り分けるため、
　もう1つ別の叩き方（例: Gmailなら `search_threads` を直近1日で）を試す。ここを雑にしない。

結果を表で出す。**繋がっていないものだけ**を次の手順に持っていく。全部繋がっていれば4へ飛ぶ。

## 3. 繋がっていないものを案内して、繋がったか確かめる

**1つずつやる。まとめて頼まない。** 4つ並べると、たいてい1つ目で止まって残りが宙に浮く。

１）道順を出す: claude.ai → 設定 → コネクタ → 該当のものを選ぶ → **構想日本のアカウント（@kosonippon.org）で**認可。
２）「繋ぎました」と言われたら、**手順2と同じ叩き方をもう一度やる**。
３）通っていなければ、通らなかった事実をそのまま伝えて、原因の切り分けに入る（アカウント違い／権限の取りこぼし／403）。
　　**「たぶん大丈夫です」で先に進まない。**
４）通ったら次の1つへ。

優先順位は **カレンダー → Gmail → Slack → GitHub → Drive → Tactiq**。
上2つが通れば実用になるので、残りは「あとでいい」と伝えてよい。全部揃うまで粘らない。

## 4. 朝のルーティンを作る

１）**何時がいいかを聞く**（日本時間で）。始業の30分前くらいを勧める。
２）**UTCに変換する。** 日本時間 − 9時間。日付をまたぐことに注意（例: 8:00 JST → 前日 23:00 UTC → cron は `0 23 * * *`）。
　　毎日なら曜日欄は `*`。平日だけなら、JSTの月〜金はUTCでは日〜木になるので `0 23 * * 0-4`。ここは間違えやすいので必ず声に出して確認する。
３）ルーティン作成のツール（`create_trigger`）で作る。**このセッションに紐づける**（`persist_session`）。
４）中身は最初は軽くする。**日次同期のような重いものを最初から渡さない。**

初期プロンプトの型（そのまま使ってよい）:

```
おはようございます。今日の準備を3つだけ教えてください。

1. 今日の予定（時刻つき。準備が要るものには「要準備」と付ける）
2. 昨日以降に届いた、返事が必要そうなメール・Slack（3件まで）
3. thinking-log/NOW.md に書いてある「次にやること」の先頭

長く書かない。全部で15行以内。
```

５）**作った直後に必ず言う**（ここを飛ばさない）:

> ルーティンを作りました。**このあと1つだけ、画面での操作をお願いします。**
> claude.ai のルーティン設定を開いて、いま作ったものに**コネクタを紐づけて**ください（カレンダーとGmail）。
> ルーティンのコネクタは普段のチャットとは別建てで、自動では引き継がれません。
> 付け忘れると、エラーも出さずに「今日は特にありません」と返ってくるので気づけません。

６）翌朝ちゃんと動いたかを、次の会話で確認すると約束する。

## 5. 最後に、明日の1手だけ渡す

やり方を全部説明しない。翌朝やることを1つだけ渡して終わる。

> 明日の朝、ここを開いて「昨日の続きは?」と聞いてみてください。それだけで大丈夫です。

そのうえで `thinking-log/NOW.md` を今日の内容で更新して commit + push する（＝翌朝それが読まれる）。

## やらないこと

・**手順書を読み上げる。** 読むだけなら `SETUP.md` を渡せば足りる。このスキルは叩いて確かめるためにある。
・**全コネクタが揃うまで粘る。** カレンダーとGmailで実用になる。残りは必要になってから。
・**日次同期・週次同期をいきなり渡す。** あれは田中さんの型。欲しがってから足す。
・**タスク管理の話を混ぜる。** ボールの管理は各自のやり方でよい。ここで押し付けない。
