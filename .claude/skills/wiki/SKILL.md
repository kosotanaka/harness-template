# kosowiki行き — 共有知をPRで積む

kosowiki（`kosotanaka/kosowiki`）は構想日本の共有ナレッジベース。
**mainへ直接コミットしない。必ずブランチ＋PR。マージは田中。**

## 手順

１）**蒸留する。** いまの文脈から「みんなが知っておくといい」部分だけを抜く。
　・積むもの: 案件の節目・決定と理由／やり方のコツ／自治体との経緯／判断の型
　・積まないもの: 個人のTODO・日々のタスク（このハーネスに留める）
２）**kosowikiのルールを読む。** `kosotanaka/kosowiki` の `AGENTS.md`（棚の定義・ノードの型・ライフサイクル）。
３）**載せない線チェック**（`行動指針/情報の扱い方.md`）: 秘密の値／住民の生の声／人事報酬健康／組織のお金と会員の機微／出典なき断定。触れそうなら**PRを作らずユーザーに「田中さんへ相談を」と案内**する。
４）**置き場所を決める。**
　・進行中案件の動き → `案件/2026年度/` の該当ページ「直近の動き」に追記
　・やり方のコツ → `事業/`（自分ごと化会議配下の手法ページ等）
　・自治体の歴史に残すこと → `自治体/<都道府県>/<市町村>.md`
　・迷ったら → `未分類/`（棚の新設はしない）
５）**PRを作る。** ブランチ名 `wiki/<自分の名前>-<テーマ>`。既存ページは節に追記し `updated:` を今日に。新規ページは `_templates/` のひな型から。1テーマ1PR。
　・GitHub MCP（create_branch → push_files → create_pull_request）か、cloneしてgitで。どちらでも可。
　・kosowikiに書く権限がない・手段がない場合は、整形済みの本文をユーザーに渡して「田中さんにSlackで送ってください」と案内する（書けないからと諦めて捨てない）。
　・PR本文: 何を足したか＋出典（会話・会議・資料）を2〜3行。
６）**PRのURLを報告**して終わり。マージは田中の判断。

## 作法

- 出典のない断定を書かない（source_refs か ⚠️未確認）。
- statusフィールドは書かない（状態＝フォルダの原則。書庫だけ例外）。
- リンクは `[[ファイル名]]`。パス直書きしない。
