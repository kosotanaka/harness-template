# 共有側へ出す — kosoproject と kosowiki の振り分け

置き場は**2つある**。まず行き先を決めるのが仕事の半分。

| 出すもの | 行き先 | 出し方 |
|---|---|---|
| **進行中案件の動き・節目・決定** | `kosotanaka/kosoproject` の該当案件ファイル | **mainへ直接コミット**（PR不要） |
| **これからやること（TODO）** | `kosotanaka/kosoproject` の **Issue** | 起票＋担当者を割り当て |
| **やり方のコツ・自治体の歴史・判断の型** | `kosotanaka/kosowiki` | **ブランチ＋PR。マージは田中** |
| 個人の作業メモ | このハーネス | 出さない |

**分けている理由は変化の速さ。** kosoproject は毎日動いて構造も変わる。kosowiki は正確さが命でめったに動かない。
迷ったら **kosoproject の案件ファイル**に書く。あとから kosowiki へ移せる。

## 手順

１）**蒸留する。** いまの文脈から「みんなが知っておくといい」部分だけを抜く。個人のTODO・作業ログは出さない。

２）**行き先を決める。** 上の表で判定する。迷う典型:
　・「◯◯市の件、こう決めた」→ **kosoproject** の案件ファイル「経緯と決定」
　・「◯◯市の第2回が終わった」→ **kosoproject** の案件ファイル「直近の動き」
　・「無作為抽出の応募率は2〜4%が相場」→ **kosowiki** の手法ページ（PR）＝案件を超えて効く知見
　・「あの町は5年前にこういう経緯がある」→ **kosowiki** の自治体ページ（PR）
　・「来週までに案内文書を送る」→ **kosoproject の Issue**

３）**載せない線チェック**（kosowiki `行動指針/情報の扱い方.md`）: 秘密の値／住民の生の声／人事・報酬・健康／**組織のお金と会員の機微**／出典なき断定。
　触れそうなら**書かずにユーザーへ「田中さんへ相談を」と案内**する。両リポ共通のルール。

４）**ルールを読む。** 行き先リポの `AGENTS.md`（棚の定義・ノードの型・ライフサイクル）。読まずに書かない。

### kosoproject へ出す場合

５a）該当ファイル（`2026/自分ごと化会議/<相手>_2026.md` または `2026/研修・その他/...`）の該当節に追記する。
　・「直近の動き」は**先頭に**日付つきで1〜3行。既存行を書き換えない・消さない。
　・`updated:` を今日に。
　・**mainへ直接コミット**（PRを作らない）。コミットメッセージに自分の名前を添える。
　・ファイルが無い新案件は `_templates/案件.md` から。ファイル名は `<相手>_<年度>.md`。**年度を必ず付ける**＝kosowikiの自治体ページと同名になるとリンクの解決先が壊れる。
　・**新しい事業区分フォルダは作らない**（田中の判断事項）。
６a）タスクが伴うなら合わせてIssueを起票し、案件名ラベルと担当者を付ける。

### kosowiki へ出す場合

５b）ブランチ `wiki/<自分の名前>-<テーマ>` を切り、既存ページの節に追記して `updated:` を今日にする。新規ページは `_templates/` から。1テーマ1PR。
　・分類に迷ったら `未分類/`。**棚の新設はしない。**
　・`status` は書かない（状態＝置き場所。書庫だけ例外）。
６b）PRを作る。本文は「何を足したか＋出典（会話・会議・資料）」を2〜3行。

## 案件が終わったとき（収穫の儀式）

**この4つはセット。1つでも欠けると、やったことが誰にも残らない。**

1. 教訓・結果の要約を1段落、**kosowiki** の `自治体/<都道府県>/<市町村>.md`「歴史・経緯」へ（**PR**）
2. その自治体ページの `> 🔥 いま動いている:` の行を消す（同じPRで）
3. 案件ファイルを kosoproject から **kosowiki の `書庫/`** へ引っ越し、`status: 完了`（または `休止`）を付ける
4. 関連Issueをクローズ

## 作法

- 出典のない断定を書かない（`source_refs` か ⚠️未確認）。埋めた顔をしない。
- リンクは `[[ファイル名]]`。パス直書き・URL直書きをしない。**両リポは同一vault前提**なのでリポを跨いでも解決する。
- 書く権限や手段が無い場合は、整形済みの本文をユーザーに渡して「田中さんにSlackで送ってください」と案内する。**書けないからと諦めて捨てない。**
- 終わったら**コミットのURLかPRのURL**を報告する。
