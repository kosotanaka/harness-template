# あなたのAIハーネス

これは構想日本メンバー用の「個人AIハーネス」のテンプレートです。
`Use this template` ボタンから、あなた専用の**プライベート**リポジトリを作って使ってください。

## これは何？

あなたとAI（Claude）が一緒に働くための、**あなた専用の記憶置き場**です。
会話は使い捨てですが、ここに残したものはAIが次回も覚えていてくれます。

・中身はあなたの私物。誰とも共有しません。
・共有すべき知見は、別途 [kosowiki](https://github.com/kosotanaka/kosowiki)（みんなのWiki）へ。

## 最初にやること（10分）

１）このテンプレから自分のリポジトリを作る（`Use this template` →名前を決めて **Private**）
２）Claude Code（claude.ai/code）から、このリポジトリに接続する
３）Claudeに **「セットアップして」** と言う

３でClaudeがやること: 自己紹介欄（`AGENTS.md`）を一緒に埋める → メール・カレンダー・Slackが繋がっているかを
**実際に叩いて確認**する → 繋がっていないものを1つずつ案内する → 繋がったか**もう一度確かめる** → 朝のルーティンを作る。

**このリポジトリをコピーしただけでは半分です。** 残りの半分（コネクタの認可・ルーティン）は
claude.ai 側の設定なので、上の３で片付きます。人間向けの説明は [SETUP.md](SETUP.md)。

## 毎日の使い方

・**始めるとき**: Claudeが自動で `thinking-log/NOW.md`（前回の続き）を読みます。
・**終わるとき**: 「チェックポイント」と言えば、Claudeが `NOW.md` を更新して保存します。
・**決めごとがあったとき**: 「ログ残して」と言えば、`thinking-log/` に記録します。

## 中身

| ファイル | 役割 |
|---|---|
| `AGENTS.md` | AIへの指示書（あなたは誰か・どう働きたいか） |
| `thinking-log/NOW.md` | いまの作業状態（揮発メモ・毎回更新） |
| `thinking-log/` | 決定と思考の記録（残す価値のあるもの） |
| `.claude/settings.json` | セッション開始時にNOW.mdを自動で読む設定 |
| `SETUP.md` | リポジトリの外でやること（コネクタの認可・ルーティン） |

## 合図（覚えるのはこれだけ）

| 言うこと | 起きること |
|---|---|
| セットアップして | 初期設定。コネクタの確認とルーティン作成まで |
| チェックポイント | いまの作業状態を保存（`NOW.md`）|
| ログ残して | 決定と理由を記録（`thinking-log/`）|
| これkosowiki行きにして | みんなの知見としてWikiへPR |

詰まったら田中まで。
