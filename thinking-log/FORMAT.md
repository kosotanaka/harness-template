# thinking-log の書き方

思考の軌跡と意思決定の理由を残す場所。成果物ではなく「なぜそう考えたか」を書く。

## ルール

１）1テーマ1ファイル。`thinking-log/YYYY/YYYY-MM-DD_テーマ.md`
２）冒頭に結論。経緯はその下。読み返す未来の自分（とAI）が3分で文脈を取り戻せる形に。
３）文体は自由。ただし判断の理由と、捨てた選択肢は書く。
４）決定には「この前提が崩れたら再検討する」を1行つける。
５）書き終えたらcommit。

## ひな型

```
# テーマ

日付: YYYY-MM-DD
状態: 検討中 | 決定 | 保留

## 結論（いまの答え）

## 経緯・理由

## 捨てた選択肢とその理由

## 見直し条件（この前提が崩れたら再検討）

## 次にやること
```
